🚀 Getting started ≈ 5 min

Tracket shows your Asana time for the day, live. It needs two things from you: your Asana “token” (so it can read your logged time) and a tiny browser script (so it can see the timer that’s running right now).

Step A — Log in

  1. Open Tracket and click Log in. Use the email and password from your welcome email.
  2. Change your password any time: ⚙ Settings → Password.

Step B — Connect Asana

  1. Tracket asks for a token right after you log in. Open Asana’s developer console in a new tab.
  2. Click + Create new token, name it Tracket, tick the box, click Create token.
  3. Click Copy (Asana shows it only once), go back to Tracket, paste it and click Connect.

Your token is stored encrypted. Tracket only reads your time — the one thing it ever changes is lunch time you ask it to remove.

Step C — Add the live-timer script

Pick your browser:

  1. Install Userscripts from the Mac App Store (free) and open it once.
  2. In Safari: Safari → Settings → Extensions → tick Userscripts.
  3. Open app.asana.com. Click the Userscripts icon next to the address bar → Always Allow on This Website.
  4. In Tracket: ⚙ Settings → Live timer → Set up live timer → Copy my script.
  5. Click the Userscripts icon → Open Extension Page → + → New JS. Press ⌘A, then ⌘V, then ⌘S.
  6. Reload your Asana tab. When Safari asks if Userscripts may use the Tracket site, choose Always Allow. (Not “for one day”, and not Deny — the live timer would silently stop.)
  1. Install Tampermonkey (free).
  2. Open your browser’s extensions page (chrome://extensions, brave://extensions or edge://extensions) → Tampermonkey → Details → turn on Allow User Scripts. (Don’t see it? Turn on Developer mode, top right.)
  3. In Tracket: ⚙ Settings → Live timer → Set up live timer → Install my script → Tampermonkey opens → Install.
  4. Reload your Asana tab. If Tampermonkey asks about the Tracket site, choose Always allow domain.
  1. Install Tampermonkey (free).
  2. In Tracket: ⚙ Settings → Live timer → Set up live timer → Install my script → Install.
  3. Reload your Asana tab. If asked about the Tracket site, choose Always allow domain.
✅ Check it works: start a timer on any Asana ticket. Within a few seconds it shows up in Tracket under On air, and the Asana link pill at the top turns green.
💡 Keep one Asana tab open (it can sit in the background). Close Asana and Tracket still shows your logged time — only the live timer pauses.
🔄 When Tracket says “Update your Asana script”, repeat Step C: delete the old Tracket script in Userscripts/Tampermonkey first, then add the new one.

🕘 Your work shift ≈ 1 min

  1. On the dashboard, click Set shift (under the big number), or ⚙ Settings → Work shift.
  2. Tick your working days and set start and end times. Copy Monday’s hours fills the rest.
  3. Click Save shift.

You then see time left, a score (100 = on track for the 7-hour minimum) and where you’ll land by the end of your shift. Reminders and your daily email use these hours too.

⚙ Auto mode ≈ 1 min

Tracket can press Asana’s timer buttons for you:

  • Daily limit — stop your timer when today reaches a number of hours (7 by default).
  • Lunch — stop the timer when lunch starts, and start it again on the same ticket when lunch ends.

Turn it on

  1. On the dashboard, find ⚙ Auto mode under your shift → Configure.
  2. Tick Stop my timer when today reaches… and pick the hours.
  3. For lunch: set your lunch start and end, then tick Stop the timer when lunch starts…
  4. Click Save.

What happens

Before doing anything, a card appears in your Asana tab and in Tracket: “Stopping your timer — 7h reached · 25” with a countdown and a Deny button. You also get a notification. Do nothing and it happens after 25 seconds; tap Deny and it won’t, for the rest of the day.

It only works while an Asana tab is open with the latest Tracket script. If Asana is closed, nothing happens automatically — on purpose, so Tracket never changes your time on its own.

🍽 Lunch ≈ 30 sec

  1. Set your lunch times in ⚙ Auto mode → Configure → Lunch break (you don’t have to turn on the auto stop).
  2. Lunch now shows as a striped band on your shift bar, and any logged time that ran through lunch is striped on the day bar.
  3. If a timer ran through lunch, the ticket shows 🍽 … during lunch · Remove lunch. Click it and confirm — Tracket takes those minutes off that entry in Asana.

Only time from a running timer is checked, never time you typed in by hand.

💬 “Did you comment?” check

If you logged time on a ticket today but didn’t post a comment on it today, the ticket shows 💬 “Dude, you forgot to mention what you did on this ticket. All good?” You get the same nudge when you stop the timer, and a summary at the end of your shift. Post a comment on the ticket in Asana and it clears within a couple of minutes.

📧 Daily email report ≈ 30 sec

  1. ⚙ Settings → Daily email report → tick Email me a daily report.
  2. Click Send today’s report now to see what it looks like (check spam the first time and mark it “not spam”).

It arrives 30 minutes after your shift ends (or at 8 pm on days without a shift): your total, every ticket, anything worth a second look, and all reminders of the day. It goes to your login email — change it in ⚙ Settings → Email.

Your running timer, ticking to the second, and today’s total — always visible at the top of your screen, whatever app you’re in:

  2. It asks for a plugin folder: make a new folder called SwiftBar in your home folder and choose it.

  4. Open Terminal (press ⌘ Space, type Terminal, press Return), paste with ⌘V and press Return. It says “Tracket plugin installed”.

🛟 Problems?

My running timer doesn’t show up in Tracket
  • Is an Asana tab open? It can be in the background.
  • Safari: click the Userscripts icon on the Asana tab and make sure it’s allowed there, and that you chose Always Allow for the Tracket site.
  • Chrome/Brave/Edge: Tampermonkey needs Allow User Scripts on (Step C).
  • Reload the Asana tab. A small orange note in its corner tells you if the script can’t reach Tracket.
Tracket says “Asana tab stopped reporting”
Your browser is blocking the script from talking to Tracket. Safari: Userscripts icon → Always Allow for both app.asana.com and the Tracket site. Tampermonkey: allow the Tracket domain. Then reload the Asana tab.
Notifications don’t arrive
Settings → Notifications → Send a test. Nothing? Check Focus/Do Not Disturb, and your device’s notification settings for Safari/Chrome or the Tracket app. On iPhone, notifications only work from the Home Screen app. Turning it off and on again in Settings also helps.
Auto mode didn’t stop my timer
It needs an open Asana tab with the latest script. If it couldn’t press the button you get a notification saying so — stop the timer by hand. If Tracket shows “Update your Asana script”, do Step C again.
The menu bar item doesn’t appear
Make sure SwiftBar is running (its icon is in the menu bar). SwiftBar menu → Open Plugin Folder — you should see tracket.js. If not, run the install command again. If it shows “Key no longer valid”, copy a fresh install command from Settings.
I use a new computer or browser
Log in, then do Step C on that browser. Your Asana token is already connected. Turn on notifications again on each new device.
